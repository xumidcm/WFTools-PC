# 截图目录

README 引用本目录的三张截图：

| 文件 | 内容 |
|---|---|
| `home.png` | 首页：最近项目、继续上次会话、草稿恢复 |
| `editor.png` | 编辑器：宽窗口下图层、画布、属性三栏 |
| `market.png` | 表盘市场窗口 |

可选补充：`agent.png`（AI Agent 面板）。补上后在两个 README 的截图章节再加一张即可。

更换截图时注意：

- PNG，宽度不小于 1280 px。
- 不要包含真实账号头像、用户名、邮箱或 API Key。
- 不要包含无权公开的付费表盘画面；用自制表盘或已获授权的样本。
- 首页截图底部的开发者联系方式属于应用本身的设计元素，公开前请确认你接受它在仓库中出现。
