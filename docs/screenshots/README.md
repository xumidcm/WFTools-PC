# 截图目录

README 的「截图」章节引用本目录下的四张图：

| 文件 | 内容 |
|---|---|
| `home.png` | 首页：最近项目、继续上次会话、草稿恢复 |
| `editor.png` | 编辑器：1280×800 宽窗口，图层、画布、属性三栏 |
| `market.png` | 表盘市场窗口 |
| `agent.png` | AI Agent 面板 |

要求：

- PNG，宽度不小于 1280 px，界面语言任选（建议中文与英文各一套，但 README 目前只用一套）。
- 不要包含真实账号头像、用户名、邮箱或 API Key。
- 不要包含无权公开的付费表盘画面；用自制表盘或已获授权的样本。
- 图片放好后，删除 `README.md` 与 `README.zh-CN.md` 中「截图」章节的 HTML 注释标记即可显示。
