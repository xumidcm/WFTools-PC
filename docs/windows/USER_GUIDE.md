# WFTools-PC 使用说明

## 打开与保存

打开 `.watch` 文件，或将多个 `.watch` 拖入窗口。每个表盘使用独立窗口；重复打开同一路径会激活已有窗口。便携版需完整解压，保留 EXE 旁的 `app` 和 `runtime` 文件夹。

- `Ctrl+O`：打开；`Ctrl+N`：新建。
- `Ctrl+S`：保存原文件；`Ctrl+Shift+S`：另存为。
- `Ctrl+W`：关闭当前窗口。有未保存修改时可选择保存、放弃或取消。
- 源文件被其他软件修改后，保存会提示重新加载、另存为或取消，避免覆盖外部修改。
- 下次启动可以恢复未保存草稿。每个文档独立保留最近 50 步撤销历史。

打开不会改写原件。保存保留未知 XML、脚本和未引用资源；未修改的文件直接保存时不会重新打包。新建或编辑过的文档采用临时归档、重新读取校验和原子替换。

## 键鼠编辑

| 操作 | 方法 |
|---|---|
| 选择图层 | 点击图层列表或画布 |
| 增减选区 | Ctrl 点击 |
| 连续范围 | Shift 点击；Ctrl+Shift 点击追加范围 |
| 搜索与筛选 | 图层面板的搜索框及类型选择器；范围选择按当前可见顺序计算 |
| 右键菜单 | 对已选中图层右击保留多选；包含复制、创建副本、删除、显隐与排序 |
| 复制／粘贴 | Ctrl+C／Ctrl+V |
| 创建副本 | Ctrl+D |
| 删除图层 | Delete |
| 撤销／重做 | Ctrl+Z／Ctrl+Y |
| 全选当前可见图层 | Ctrl+A |
| 画布微移 | 方向键移动 1 个设计单位；Shift 为 10；Alt 为 0.1 |
| 拖动约束 | Shift 约束单轴；Alt 暂时关闭吸附 |
| 缩放 | 滚轮以鼠标位置为中心缩放；工具条提供适合窗口和 100% |
| 平移 | 中键拖动，或空格＋左键拖动 |

输入框获得焦点后，方向键、Delete、复制、全选和撤销由输入框处理。单行属性按 Enter 提交；离开输入框也会提交。长表达式使用展开编辑，保留原表达式；画布移动会在原表达式上合成位移增量。

## 素材

把图片、GIF/WebP 动画、视频、字体或位图字体描述文件及配套图集拖入：

- 设备预览：复制素材并在落点创建图层。
- 素材面板：只入库。
- 兼容的路径／字体属性：替换引用。

同名素材自动避让。整批导入对应一次撤销；失败不会保留半完成的编辑。外部素材原件不会移动。表盘和素材混合拖入时需要分开操作。

## 设备预览

提供 480×480、320×386、368×448、410×502，以及 64–2048 范围的自定义宽高。形状可以跟随原表盘、覆盖为圆形或矩形。

默认等比铺满并居中裁切；可在预览面板切换完整显示、按高、按宽、拉伸、自定义，并调整双轴倍率和偏移。设备设置仅模拟运行时视口；编辑坐标与缩略图导出仍来自原文档。工作区放大和平移也不会写入 `.watch`。

编辑模式选择和移动图层；交互模式执行表盘的点击动作。预览面板可控制时间、播放、亮屏／息屏、主题及模拟传感器数据。手机应用、系统设置等动作显示模拟结果；表盘 Lua、秒表、主题切换和素材声音在本地运行。

## 窗口与外观

默认跟随 Windows 明暗主题，可通过“外观”菜单手动切换。宽窗口使用三栏，较窄窗口改为预览和标签侧栏，最窄时改为上下布局。拖动面板之间的分隔条调整空间，属性面板可独立滚动。

## 当前边界

只支持 Windows x64 和 `.watch`。HSC、WFF 转换、市场下载、AI 及独立素材工具不在本版范围。上游未实现的 `gallery_2d` 与未知图层仅保留数据并显示说明。受保护的 `watch.pxml` 需由文件所有者在原工具中导出可编辑版本。

地图需要联网；可穿戴传感器采用模拟值。实际安装、默认打开方式及跨显示器观感的验收范围以随包验收记录为准。
