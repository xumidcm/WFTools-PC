# 全局画布开关设计

## 目标

让首页设置和编辑器右上角三点菜单共享完整的画布开关，并在应用重启、切换文档及同时打开多个编辑窗口时保持一致。

## 设置边界

应用级 `CanvasInputPreferences` 统一保存六个布尔开关：

- 中键拖动画布；
- 右键拖动画布；
- 滚轮缩放选中元素；
- 自动吸附；
- 变换控制点；
- 显示操作状态提示。

六项默认开启，写入 `application.properties`。在任一入口修改后，所有已打开编辑窗口立即读取新状态，重启后继续生效。

“鼠标直拖／先选后拖”是文档级操作模式，继续保存在对应表盘的预览偏好中，不加入首页设置。

## 界面

首页设置弹窗的“画布操作”区域展示六个开关及完整操作说明。编辑器三点菜单的“画布设置”页保留同名开关，只展示简洁标签，不重复说明。

## 数据流

`EditorApplicationModel` 持有唯一的 `CanvasInputPreferences` 状态。首页设置和编辑器菜单都通过复制该值更新单项字段；`Main` 监听整体值并与主题、窗口和面板偏好一起延迟写盘。画布预览、控制点和状态栏直接读取应用级状态，不再由当前文档的同名旧字段决定。

旧版文档偏好中的 `snapping`、`showTransformHandles` 和 `showOperationStatus` 暂时保留用于文件兼容，但不再作为界面状态源，避免同一功能存在两份可变状态。

## 验证

- 偏好测试验证六项默认值、保存和重启恢复。
- 首页 Compose 测试验证六项开关存在并能更新共享状态。
- 编辑器 Compose 测试验证同一状态驱动画布设置、控制点与状态提示。
- 全量运行 `watch-core`、`watch-renderer` 和 `desktopApp` 测试。
