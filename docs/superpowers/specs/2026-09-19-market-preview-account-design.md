# 表盘市场头像、详情缓存与账号记忆设计

## 范围

本次只修改 WFTools-PC 桌面端，不触碰 Flue。目标是让市场详情在完整数据到达前显示明确加载态，补齐账号头像与登录会话持久化，并保持受保护表盘直开能力为默认隐藏、默认关闭。

## 方案

- `MarketAccountApi` 增加按站点根解析的同源头像字节读取；资料页、市场窗口右上角账号按钮和 Dashboard 左上角共用头像加载/缓存，失败时只回退用户名首字母，不显示成功/失败状态文案。
- 市场详情请求期间只显示转圈加载态，不先闪现列表缓存内容；完整详情到达后一次性展示。预览继续统一归一化为 512×512。
- 新增可注入的本地凭据存储：账号名按“记住账号”保存，Windows 密码按“记住密码”使用用户绑定 DPAPI 保护，其他环境使用 AES-GCM 回退；另用同样的用户绑定保护持久化会话 token、用户摘要和 JWT 过期时间。启动/打开市场时恢复并用 `/my/me` 校验，只有手动退出或收到 token 失效（401）才清除会话；登录/注册成功后同时写入会话与勾选项，重新打开登录面板时预填。
- 上传页在已选文件的同一操作行显示“分析并读取表盘信息”，不改变服务器两步扫描/上传协议。
- 删除详情底部受保护说明卡，只保留受保护状态徽章；现有 `ProtectedFacePreferences` 的 `unlocked=false`、`allowEditing=false` 默认值不变。
- 将“继续上次的会话”移动到主界面右上角，保留原有恢复逻辑和测试标签。
- 版本源、Windows/Linux 打包默认版本同步到 `0.1.6`。

## 验证

先添加 API/凭据/详情状态的回归测试并确认红灯，再实现；随后运行桌面端与 watch-renderer 测试、`git diff --check`，最后用新的版本目录构建 Windows/Linux 包并生成 SHA-256。
