# 画布输入与共享设置设计

## 目标

统一桌面编辑器的画布平移和滚轮行为，并让主页设置弹窗与编辑器右上角三点菜单操作同一份持久化设置。

## 设置模型

新增应用级 `CanvasInputPreferences`，默认保持现有手感并启用新增能力：

- 中键拖动画布：默认开启。
- 右键拖动画布：默认开启。
- 滚轮缩放选中元素：默认开启；关闭后滚轮始终缩放整个表盘。

设置写入 `application.properties`，不属于单个 `.watch` 文档。主页和编辑器共享同一状态，任一入口修改后另一入口立即反映，重启后继续生效。

## 交互规则

- “先选后拖”模式没有选中元素时，左键拖动空白或图层区域均平移整个表盘；短按仍执行原有选择。
- 开启右键拖动后，右键移动超过拖动阈值即平移表盘，不移动图层，也不因拖动改变选择；短按右键保留原有上下文行为。
- 开启中键拖动后，按住滚轮立即进入画布平移；关闭后中键不接管画布。
- “滚轮缩放选中元素”开启时，光标位于选中元素上会缩放元素，其余位置缩放表盘；关闭后滚轮无论光标位置都缩放表盘。
- Ctrl+滚轮始终缩放表盘；空格加左键、Ctrl 加左键等已有画布操作保持不变。
- 文档正在接受外部编辑或已有变换手势时，继续沿用现有输入保护，不并发启动新的画布手势。

## 设置界面

- 主页设置弹窗：展示三个开关，并在其下说明直接拖动、先选后拖、空选区平移、中键、右键、滚轮与 Ctrl/空格快捷操作。
- 编辑器右上角三点菜单的“画布”页：展示同样三个开关，但不重复长说明。

## 验证

- 纯逻辑测试覆盖空选区拖动、左右中键开关及滚轮分流。
- 偏好测试覆盖默认值、保存、恢复及旧配置兼容。
- Compose 语义测试覆盖主页和编辑器两个入口均存在三个开关。
- 运行渲染器、桌面端相关测试，最后串行运行全量测试；鼠标阻力和阈值手感由用户在真实设备上验收。
